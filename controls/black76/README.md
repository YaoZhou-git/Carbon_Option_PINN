# Black (1976) futures-option comparison

This script illustrates maturity-curve crossings and a zero-rate comparison using the Black (1976) futures-option formula.

Run `python black76_demo.py` from this directory. It evaluates the analytic formula, checks Gaussian integrals, and writes plots and CSVs. `verification.json` contains saved numerical checks.

Chinese plot labels require a locally installed CJK font.
